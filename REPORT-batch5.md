## Что сделано

### Работа с файлами (workspace-инструменты) — всё из списка
- **Diff-просмотр перед записью** — в нативном диалоге подтверждения теперь показывается unified diff (своя LCS-реализация, лимит 1500 строк) вместо просто имени файла.
- **`edit_file`** — точечная замена уникального фрагмента (ошибка, если фрагмент не найден или встречается >1 раза).
- **`apply_patch`** — применение unified diff к нескольким файлам с поиском сдвинутого контекста (±20 строк).
- **`run_command`** — allowlist dev-команд (npm, git, tsc, python и т.д.), запрет пайпов/редиректов/цепочек, таймаут 60 с, вывод до 32 КБ, всегда с подтверждением.
- **История изменений с откатом** — перед каждой записью снапшот в `.lumen-backup/<timestamp>/` (хранится 50 последних); панель «Workspace activity» (иконка часов в тулбаре) с логом всех операций и кнопкой «Roll back».
- **Глобальный workspace по умолчанию** — в настройках (Appearance), используется, когда у чата нет своей папки.

### Продуктивность чата
- **Экспорт HTML/PDF** — красивый standalone HTML (рендерится той же markdown-цепочкой), PDF печатается из скрытого окна. Settings → Data.
- **Голосовой ввод** — кнопка микрофона в композере (Web Speech API, ru-RU, с interim-результатами).
- **Шаблоны промптов** — с переменной `{{input}}`; редактор в Settings → Personas, кнопка в композере, `/template N`.
- **Slash-команды** — `/model`, `/persona`, `/template N`, `/clear`, `/summarize`, `/readonly`, `/help`.
- **Summarize** — сжатие длинного чата (мини-запрос), модалка с кнопкой «New chat from summary»; история не трогается.
- **Закладки** — флажок на сообщении + липкая панель закладок над лентой с прыжками.

### Организация
- **Поиск с фильтрами** — дата (от/до), модель, роль, папка, тег; иконка-воронка в поисковой строке.
- **Теги чатов** — редактор через запятую (иконка тега в строке чата), чипсы кликабельны (сразу фильтр поиска).
- **Архив чатов** — сворачиваемая секция внизу сайдбара, архивация/разархивация из строки чата и тулбара.
- **Бэкап/восстановление** — Settings → Data: копия БД + вложений в выбранную папку; восстановление с перезапуском и сохранением `.pre-restore`.

### Интерфейс
- **Кастомные CSS-темы** — загрузка .css файла (до 100 КБ), инжектится в окно.
- **Компактный режим** — переключатель в Appearance.
- **Focus mode** — кнопка в тулбаре, скрывает сайдбар/лишнее, Esc выходит.
- **Always-on-top** — кнопка-пин в тулбаре.
- **Lightbox** — клик по картинке открывает на весь экран.
- **Сворачивание длинных сообщений** — >3000 символов схлопываются с градиентом.
- **Счётчик токенов** в композере (~оценка + стоимость input по прайсу модели).
- **Markdown-предпросмотр** черновика (кнопка-глаз).
- **Unread-бейджи** — точка на чате, чей ответ завершился, пока ты был в другом.
- **Страница статистики** — Settings → Statistics, бары токенов/стоимости по дням (30 дней).
- **TTS** — кнопка «читать вслух» на ответах (speechSynthesis).
- **Copy-as-quote** — цитата с моделью и датой.
- **Прогресс-бар** генерации (indeterminate — точный прогресс неизвестен mid-stream).
- **«Пока вас не было»** — тост при возврате фокуса, если ответы завершились в фоне.

### Продвинутые инструменты (electron)
- `read_many`, `get_file_info`, `create_folder`/`delete_file`/`move_file`, `read_file` с диапазоном строк, `find_definition`/`find_references` (regex, word-boundary), `diff_files`.
- **Дерево проекта** в системном промпте (первое сообщение чата) + **LUMEN.md** (до 8 КБ) всегда, когда есть.
- **Снапшоты** в `.lumen-backup/` + откат (перед откатом текущее состояние тоже снапшотится).
- **Read-only режим** на чат (кнопка-щит в тулбаре) — модель может читать/искать, все записи отклоняются с объяснением.
- **Журнал операций** (таблица `file_ops` в БД) — что читала/писала/отклонено, со статусами ok/error/declined.
- **Лимит бюджета tool-loop** — 200k символов вывода инструментов → финальный раунд без инструментов.
- `git_status`/`git_diff`/`git_commit` (коммит с подтверждением и показом статуса).
- `memory_read`/`memory_save` — долговременная память проекта (`.lumen-memory.md`).
- `todo_write` — чек-лист задачи, живая панель в UI (обновляется по событию).
- `web_fetch` — с подтверждением домена, отказ для localhost/приватных сетей, лимит 20 КБ текста.
