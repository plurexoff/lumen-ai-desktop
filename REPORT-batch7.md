## Что сделано (все 16 пунктов из списка)

### Дёшево и заметно
1. **Типографика и ритм** — мелкий текст поднят до 10–11px минимум (подписи композера, время сообщений, селект модели), добавлен `letter-spacing: .01em` для сайдбара/тулбара/табов, ключевые отступы приведены к шкале 4/8/12/16 (сайдбар 12px, тулбар 16px, gap'ы 8/12).
2. **Глубина** — в тёмной теме бордеры светлее (`#2e323b`), появились токены теней `--shadow-1/--shadow-2`: композер, модалки, палитра, меню и тосты теперь «плавают».
3. **Пузыри сообщений** — ответы ассистента в карточке `var(--panel)` + радиус 12 + бордер; сообщения пользователя остаются чистым текстом. Закладка (бордер слева) и compact/comfy-паддинги учтены.
4. **Фокус-стили** — `:focus-visible` с обводкой акцентом 2px на кнопках, полях, селектах, табах и опциях меню.
5. **Плавность** — единый `transition: .14s ease` на всех интерактивных элементах; входные анимации для бэкдропа, модалок и тостов (fade + translateY). `prefers-reduced-motion` уже всё отключает.
6. **Скроллбары** — тонкие (10px), thumb в цвете бордера с hover в `--faint`, трек прозрачный; Firefox-синтаксис тоже прописан.

### Средние
7. **Светлая тема 2.0** — тёплый «бумажный» фон `#faf9f7`, тёплые бордеры `#e4e1db`, мягкие тени вместо жёстких рамок.
8. **Пресеты тем** — Default / **Midnight** (синевато-чёрный) / **Sepia** (тёплый коричневый); каждый пресет задаёт полную палитру для dark и light. Выбор — свотчами в Settings → Appearance, значение валидируется в main (`themePreset`).
9. **Точка провайдера** — в шапке ответа ассистента рядом с именем модели, цвет из `providerColors`.
10. **Empty states** — панели документов и активности + палитра без совпадений: иконка + фраза (+ кнопка «Attach document…» в пустой панели документов).
11. **Табы как в браузере** — активный таб «врастает» в панель (общий бордер снизу уходит), сверху акцентная полоса, неактивные приглушены, hover-подсветка.
12. **Композер как центр** — крупнее (padding 14, radius 14), кнопка отправки — акцентная таблетка, при генерации рамка пульсирует акцентом; фокусная обводка со свечением. Прогресс-бар в пузыре оставлен — он показывает активность в самой ленте.

### Крупные
13. **Дизайн-токены** — весь акцент теперь производный: `--accent-strong` / `--accent-dim` через `color-mix`; все захардкоженные фиолетовые hex (`#a48ade`, `#8870c7`, `#b69af2`, градиенты welcome/лого/кнопки) переопределены на токены — смена акцента теперь перекрашивает приложение целиком.
14. **Mica** — на Windows 11 окно создаётся с прозрачным фоном + `setBackgroundMaterial('mica')`; рендерер узнаёт об этом через `app:profile` и включает полупрозрачные тайтлбар/сайдбар/панели (класс `.mica`). На Windows 10 — прежний непрозрачный вид, ничего не ломается.
15. **Плотность** — вместо тумблера «compact mode» сегментированный выбор **Comfortable / Default / Compact** (`density` в настройках; старое поле `compactMode` синхронизируется, чтобы старые сборки читали ту же таблицу).
16. **Аватары** — у ассистента фирменная «L» на акцентном градиенте, у пользователя — первая буква логина ОС на градиенте, детерминированном по букве (стабильно между сессиями).

## Технически
- Новые поля настроек: `density`, `themePreset` (валидация в `clampSettings`, дефолты в `settings:get`, типы в `SettingsData`/`Prefs`).
- Новый IPC: `app:profile` → `{mica, username}`.
- Весь дизайн-слой — отдельная секция в конце `styles.css` (переопределения каскадом, старые плотные строки не трогал — риск регрессий минимален).
- Инсталлятор пересобран: `release\Lumen AI Setup 1.1.0.exe`. Схема БД не менялась (осталась v7).

## Нюансы
- Mica виден только на Windows 11; при неудаче `setBackgroundMaterial` приложение молча остаётся на обычных цветах.
- Пресеты и акцент комбинируются: акцент поверх палитры пресета.
- Старый инлайн-градиент аватара пользователя перекрывает любые CSS-правила (inline style) — это осознанно.
